# Расшифровка пароля из ntfy.sh уведомления

После настройки сервера через `admin_init.sh`, вы получите уведомление с зашифрованным паролем пользователя `admin_init`. Этот документ объясняет, как расшифровать пароль.

## Содержимое уведомления

Уведомление будет выглядеть примерно так:

```
🔧 Новый сервер настроен!

👤 Пользователь: admin_init
🌐 Внешний IP: 203.0.113.42
🏠 Внутренний IP: 192.168.1.100
🖥️  Hostname: my-server
💻 OS: Debian GNU/Linux 12 (bookworm)
⏰ Время: 2025-11-25 12:34:56 UTC

🔐 Пароль (зашифрован):

echo "-----BEGIN AGE ENCRYPTED FILE-----
YWdlLWVuY3J5cHRpb24ub3JnL3YxCi0+IFgyNTUxOSBxYmR0K2pHU2lqYjJy...
(несколько строк)
-----END AGE ENCRYPTED FILE-----" | age -d -i ~/.age/key.txt
```

**Команда готова к использованию** - просто скопируйте её из уведомления и выполните в терминале!

## Приватный ключ

**ВАЖНО:** Расшифровать пароль может только приватный ключ, парный публичному ключу из скрипта (`AGE_PUBLIC_KEY`). Он **не хранится в этом репозитории** — возьмите его из вашего безопасного хранилища (менеджер паролей и т.п.).

Положите его в файл `~/.age/key.txt`:

```bash
mkdir -p ~/.age
# Вставьте ваш приватный ключ (начинается с AGE-SECRET-KEY-1...)
printf '%s\n' 'AGE-SECRET-KEY-1...' > ~/.age/key.txt
chmod 600 ~/.age/key.txt  # Только владелец может читать
```

Если нужно сгенерировать **новую** пару ключей (ротация): `age-keygen` выведет приватный ключ и соответствующий публичный. Публичный ключ пропишите в `AGE_PUBLIC_KEY` в `admin_init.sh`, приватный сохраните в надёжном месте — и никогда не коммитьте его в репозиторий.

## Способ 1: Расшифровка через командную строку (рекомендуется)

### Установка age

#### Debian / Ubuntu
```bash
sudo apt-get update
sudo apt-get install age
```

#### macOS
```bash
brew install age
```

#### Windows
Скачайте бинарник с [GitHub Releases](https://github.com/FiloSottile/age/releases):
- Скачайте `age-v1.1.1-windows-amd64.zip`
- Распакуйте и добавьте `age.exe` в PATH

#### Другие системы
Скачайте подходящий бинарник с [официального сайта](https://github.com/FiloSottile/age/releases).

### Расшифровка

**Самый простой способ:** Скопируйте готовую команду прямо из уведомления ntfy.sh и выполните её в терминале!

```bash
# Команда из уведомления уже готова к использованию:
echo "-----BEGIN AGE ENCRYPTED FILE-----
YWdlLWVuY3J5cHRpb24ub3JnL3YxCi0+IFgyNTUxOSBxYmR0K2pHU2lqYjJy...
-----END AGE ENCRYPTED FILE-----" | age -d -i ~/.age/key.txt
```

Единственное, что нужно сделать:
1. Убедитесь, что у вас есть файл `~/.age/key.txt` с приватным ключом
2. Скопируйте команду из уведомления
3. Выполните её в терминале

## Безопасность

### Храните приватный ключ в безопасности:

1. **Не коммитьте в Git** — добавьте `key.txt` в `.gitignore`
2. **Ограничьте права доступа:**
   ```bash
   chmod 600 key.txt
   ```
3. **Резервное копирование:** Сделайте несколько копий ключа (флешка, менеджер паролей, бумага в сейфе)
4. **Не делитесь публично** — без этого ключа зашифрованный пароль бесполезен

### Если ключ утерян:

Если вы потеряли приватный ключ, но имеете доступ к серверу:
```bash
sudo cat /root/.admin_init_password.txt
```

Пароль также выводится в консоль при выполнении скрипта.

## Пример полного процесса

```bash
# 1. Создайте файл с приватным ключом (возьмите ключ из вашего хранилища)
mkdir -p ~/.age
printf '%s\n' 'AGE-SECRET-KEY-1...' > ~/.age/key.txt
chmod 600 ~/.age/key.txt

# 2. Установите age (если ещё не установлен)
# Debian/Ubuntu:
sudo apt-get install age
# или macOS:
# brew install age

# 3. Скопируйте команду из ntfy.sh уведомления и выполните:
echo "-----BEGIN AGE ENCRYPTED FILE-----
YWdlLWVuY3J5cHRpb24ub3JnL3YxCi0+IFgyNTUxOSBvNkxhc25sdzZMSTVz...
-----END AGE ENCRYPTED FILE-----" | age -d -i ~/.age/key.txt

# Вывод (пароль):
# xY9pQ2mK3vN8rT5w
```

## Устранение проблем

### Ошибка: "no identity matched"
- Проверьте, что используете правильный приватный ключ
- Убедитесь, что скопировали весь зашифрованный текст (включая `-----BEGIN/END-----`)

### Ошибка: "command not found: age"
- Установите age (см. раздел "Установка age")
- Проверьте, что age в PATH: `which age`

### Зашифрованный текст повреждён
- Убедитесь, что скопировали **все строки** зашифрованного текста
- Проверьте, что нет лишних пробелов или переносов строк
